# 07: 完整体验、演示模式与验收回归

**What to build:** 完成「工地」的中文桌面优先体验、临时演示模式和端到端回归，让核心流程可以从头到尾稳定演示。

**Blocked by:** 01: 项目骨架与项目列表；02: 团队成员与负责人；03: 大任务时间轴；04: 具体任务与进度规则；05: 工地房子与工人可视化；06: 附件、删除影响与共享状态

**Status:** ready-for-agent

- [ ] 首页、团队页、项目页和编辑面板形成统一的纸色、墨色、安全橙视觉风格
- [ ] 使用 Noto Sans SC；正文对比度至少 4.5:1；可点击元素具有键盘焦点态；图标使用 SVG，不使用 emoji
- [ ] 提供只存在于内存中的演示数据入口，演示数据不写入真实数据库，离开后消失
- [ ] 端到端测试覆盖创建项目、添加成员、创建大任务、添加具体任务、指派、修改状态、查看房子、附件和删除
- [ ] 回归覆盖周/月切换、拖拽、工人高亮、成员取消指派、级联删除、保存失败、轮询同步和空状态
- [ ] 窄窗口回归确认时间轴可以横向滚动
- [ ] 建立并运行浏览器端到端测试；必要时补充日期和进度纯规则测试
- [ ] 验收完整流程在真实 Node、Vite、SQLite 环境中通过
