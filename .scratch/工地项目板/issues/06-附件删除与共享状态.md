# 06: 附件、删除影响与共享状态

**What to build:** 用户可以维护具体任务的轻量附件，并在级联删除、多人访问和保存失败时获得明确且可恢复的行为。

**Blocked by:** 04: 具体任务与进度规则

**Status:** ready-for-agent

- [ ] 具体任务支持多个附件
- [ ] 名称和地址都为空的附件不保存；只有名称时显示为纯文字
- [ ] HTTP(S) 地址在新标签页打开
- [ ] 非 HTTP(S) 地址按普通路径处理，点击后复制到剪贴板
- [ ] 不上传文件、不抓取或预览链接、不执行其他协议
- [ ] 删除大任务会级联删除具体任务及附件
- [ ] 删除项目会级联删除全部下级数据
- [ ] 删除和级联影响显示具体确认提示，删除不可撤销
- [ ] 页面通过轻量轮询在数秒内看到其他浏览器已保存的更新
- [ ] 同一记录并发编辑时以后写入的值生效
- [ ] 保存失败时保留本地编辑、显示失败状态并提供重试
- [ ] 浏览器验收覆盖附件打开/复制、级联删除、第二浏览器轮询、冲突写入和失败重试
