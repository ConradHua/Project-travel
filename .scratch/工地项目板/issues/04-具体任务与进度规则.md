# 04: 具体任务与进度规则

**What to build:** 用户可以把大任务拆成具体任务，维护状态和负责人，并看到统一且准确的项目进度与状态计数。

**Blocked by:** 02: 团队成员与负责人；03: 大任务时间轴

**Status:** ready-for-agent

- [ ] 可以在大任务下添加具体任务，默认为未命名事项、未开始、未指派
- [ ] 具体任务按创建顺序排列，不支持跨大任务移动、继续拆分或手动排序
- [ ] 具体任务支持未开始、进行中、完成三种状态
- [ ] 具体任务支持选择或取消一位负责人
- [ ] 显示未开始、进行中、已完成三个计数
- [ ] 项目完成度为已完成具体任务数除以全部具体任务数
- [ ] 进行中任务进入分母但不进入分子，空大任务不进入分母
- [ ] 没有具体任务或完成数为 0 时显示 0% 和空地
- [ ] 部分进度四舍五入并限制在 1–99；全部完成显示 100%
- [ ] 删除具体任务后计数和进度立即更新
- [ ] 项目列表与项目页使用同一套进度规则
- [ ] 浏览器验收覆盖添加、状态切换、负责人选择、排序稳定性、删除和全部进度边界
