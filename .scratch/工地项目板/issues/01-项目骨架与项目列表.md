# 01: 项目骨架与项目列表

**What to build:** 用户可以启动并访问「工地」应用，创建、查看和永久删除项目；项目数据保存后可在应用重启后继续使用。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Node 22+、React、TypeScript、Vite 与 SQLite 基础应用可启动，开发环境 API 与页面同源工作
- [ ] 服务监听局域网地址，并输出可访问地址
- [ ] 空状态显示项目创建入口
- [ ] 创建项目要求名称、开工日和完工日；日期缺省为今天至 30 天后
- [ ] 项目列表显示名称、日期和 0% 空进度状态
- [ ] 项目按进行中优先、其余按创建时间倒序排列
- [ ] 删除项目需要确认，确认后永久删除
- [ ] 项目数据写入本地 SQLite，并在重启后恢复
- [ ] 浏览器验收覆盖空状态、创建、刷新、重启恢复和删除
