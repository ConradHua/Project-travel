# 05: 工地房子与工人可视化

**What to build:** 具体任务状态驱动中央房子、工人和成员完成度，形成项目进度的动态视觉反馈。

**Blocked by:** 04: 具体任务与进度规则

**Status:** ready-for-agent

- [ ] 使用分层扁平 SVG 渲染房子和工人
- [ ] 0% 显示空地；1–24% 为地基；25–49% 为框架；50–74% 为墙体和屋顶；75–99% 为门窗装修；100% 为完成状态
- [ ] 100% 时窗户亮灯
- [ ] 阶段切换约 300–400ms；系统减少动效时直接进入终态
- [ ] 有指派具体任务的成员显示在房前，并显示个人完成数/总数
- [ ] 成员参与某大任务的条件是其至少有一个具体任务归属该大任务，不受任务状态影响
- [ ] 点击工人高亮其参与的大任务，其他大任务变淡；再次点击取消
- [ ] 大任务颜色只用于时间轴条，成员颜色只用于工人
- [ ] 房子不可点击
- [ ] 浏览器验收覆盖所有阶段边界、亮灯、成员比例、工人高亮与减少动效
