# 03: 大任务时间轴

**What to build:** 用户可以在项目中创建、编辑和排期大任务，并通过周/月时间轴查看项目计划。

**Blocked by:** 01: 项目骨架与项目列表

**Status:** ready-for-agent

- [ ] 可以创建默认大任务，标题为未命名任务，日期从今天起 7 天并限制在项目工期内，创建后打开编辑面板
- [ ] 大任务包含标题、起止日期和区分色，并支持编辑与永久删除
- [ ] 项目页显示顶栏、时间轴和右侧编辑面板
- [ ] 周视图按天显示并以周一作为每周起点；月视图显示月级概览
- [ ] 周/月切换不改变任务日期；月视图不支持精确拖拽
- [ ] 周视图支持整体移动与两端调整，按天吸附，最短为一天
- [ ] 重叠大任务自动分行显示
- [ ] 大任务没有具体任务时仍显示，但使用弱化样式
- [ ] 长项目默认定位今天附近，短项目显示完整工期
- [ ] 大任务移出项目工期时自动延长项目，不自动缩短项目
- [ ] 手动修改项目工期若会排除已有大任务则拒绝并提示
- [ ] 窄窗口下时间轴可以横向滚动
- [ ] 浏览器验收覆盖创建、编辑、切换、拖动、缩放、重叠和日期约束
