# 02: 团队成员与负责人

**What to build:** 用户可以维护团队花名册，并把具体任务的负责人限制为当前花名册成员；成员信息变化会同步到所有相关界面。

**Blocked by:** 01: 项目骨架与项目列表

**Status:** ready-for-agent

- [ ] 团队页可以创建成员，成员包含名称和代表色
- [ ] 成员可以编辑名称和代表色，已指派任务中的展示同步更新
- [ ] 成员可以删除，删除前确认
- [ ] 删除成员后相关具体任务保留，但负责人变为未指派
- [ ] 没有成员时项目和任务仍可正常使用
- [ ] 负责人选择只能使用当前花名册成员或未指派
- [ ] 成员数据持久化，刷新后仍可见
- [ ] 浏览器验收覆盖创建、编辑、指派、删除和取消指派
